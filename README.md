# PRD: AI Triage Agent for Support Inbox

A sample product requirements document — written as a portfolio piece to show how I scope problems, write requirements, define metrics, and plan rollouts.

**The product:** an AI agent that triages a support inbox — classifying, auto-resolving safe tickets, routing the rest, with a human override on everything.

**Target:** cut median first response time from 7h to under 1h in one quarter.

Read it: [`PRD.md`](PRD.md)

## What's inside

- Problem framing with baseline metrics
- Goal, success metrics, and explicit non-goals
- Functional + non-functional requirements
- UX principles (trust-but-verify for agents)
- Phased rollout plan (shadow → 10% → 100%) with a kill switch
- Risks, mitigations, and open questions
